# CX-Codex 2.7.2：会话管理更顺手，远程访问恢复更可靠

2.7.2 集中改善日常高频体验：左侧会话列表更简单、更符合最近使用习惯，长会话和移动端操作更稳定，同时补上临时公网通道“进程还在、地址已失效”时的恢复能力。

## 本版重点

- 左侧固定为“置顶会话 + 目录 + 会话”三层结构。置顶会话、目录和目录内会话都按最近活动排序，最近使用的内容自然在上方。
- 目录支持一键全部收起或展开，底部新增“当前会话”定位；不再提供会与最近排序冲突的置顶目录或手动排序入口。
- 会话操作集中到统一菜单，支持置顶、标记未读、复制完整会话、Markdown 导出、复制当前站点链接、分叉、重命名和归档。
- 归档后会出现“撤销”，误操作无需再去归档区查找；菜单在窄屏、列表底部和点击外部时都能正确定位或关闭。

## 搜索与效率

- `Ctrl/Command + P` 可以搜索当前工作区文件并快速打开，最近打开的文件会按工作区保留。
- 文件搜索会复用短时间内的目录扫描、合并并发请求，并限制执行时间和输出大小，避免大型仓库拖慢服务。
- 侧栏会话搜索可先显示本地匹配，再补齐全量索引；连续输入时尽量保留仍然有效的结果和焦点，不再频繁闪空。
- 完整会话复制和导出会读取权威历史，不要求先切换到目标会话，也不会只导出当前已加载的一小段内容。

## 稳定性与移动端

- 手机默认 Enter 换行，桌面默认 Enter 发送；用户在设置中的明确选择仍然优先。输入框会随内容增高，但不会无限占用屏幕。
- “等待确认”任务会比普通运行任务更醒目；收起侧栏后仍能看到需要关注的任务数量。
- 前后台恢复时保留用户的阅读位置；页面隐藏期间停止非必要时钟与轮询，回到前台后再恢复有限同步。
- session-index 与 session-log 文件变化按来源刷新列表或消息，减少每次日志追加都重载全部会话的开销。
- 会话列表与搜索索引使用非阻塞、可合并的缓存写入；长会话的新权威快照可清理同一轮次的旧投影，降低重复内容与切换卡顿。
- 图片预览支持以双指或鼠标位置为缩放锚点，缩放后可平滑拖动；Markdown 图片失败时提供可恢复状态。

## 远程访问修复

Cloudflare Quick Tunnel 的子进程偶尔仍然存活，但临时域名或公网连接已经失效。此前再次点击开启会直接复用旧的 `ready` 状态，看起来正常，实际手机仍打不开。

2.7.2 会在复用现有临时地址前重新验证：

- 公网健康接口必须返回 HTTP 200。
- 未登录 HTTP 接口必须保持 HTTP 401。
- 未登录 WebSocket 连接必须保持鉴权拒绝。

任一验证失败都会停止旧通道并继续建立新地址，不再把失效通道误报为可用。Quick Tunnel 仍属于临时地址；需要长期固定地址时，建议使用已登录的 Tailscale Funnel 或自行维护的固定反向代理。

## 安全边界

- 文件快速搜索只接受服务端允许的工作区绝对路径，不扫描其他目录。
- 会话链接使用当前站点地址，不把访问密码写入链接。
- 会话复制和导出不修改、归档或切换目标会话。
- 远程入口继续保留密码 Cookie、HTTP 401 与 WebSocket 鉴权门禁。
- 正式 Android APK 继续由 GitHub Release 工作流使用固定证书构建并校验证书 SHA-256。

## 安装或升级

Windows 服务端可以继续使用原命令升级：

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/Qjzn/CX-Codex/main/scripts/bootstrap-windows.ps1'))) -RemoteQuick -JsonOutput
```

Android 用户可从本 Release 下载 `cx-codex-android-v2.7.2.apk` 覆盖安装。正式 APK 与 `2.5.9+` 使用同一签名，可保留已有服务地址和设置。

官方卸载入口默认保留访问配置、Codex 登录态、工作区和 Android 正式签名：

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/Qjzn/CX-Codex/main/scripts/uninstall-windows.ps1'))) -JsonOutput
```
