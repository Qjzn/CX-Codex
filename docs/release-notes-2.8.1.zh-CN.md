# CX-Codex 2.8.1

候选版本，尚未正式发布。本次聚焦远程对话的反馈、可读性与状态稳定性。

## 核心改进

- 消息发送后立即保留，确认延迟时不轻易显示失败；加强恢复过程中的身份去重。
- 公开进展文字、运行动画与本轮耗时优先展示，命令和输出按需展开；阅读历史时减少跳动。
- 修复新一轮沿用旧耗时、旧快照覆盖新状态和恢复后漏读回复的问题。
- 加固计划、目标与队列的一致性，并合入依赖安全及 Windows 启动器修复。

## 安装与升级

正式发布前继续使用现有稳定版，不将 beta 当成已发布升级。正式发布后沿用 `scripts/bootstrap-windows.ps1` 的 `-RemoteQuick -JsonOutput` 安装流程，并核对发布资产的 SHA-256。

卸载入口为 `scripts/uninstall-windows.ps1`，默认保留配置和认证。升级应保留上一份健康安装及私有状态备份；回滚不得盲目覆盖已产生新消息的数据库。

## 验收边界

为避免重复执行，排队消息暂不支持直接编辑或立即引用，原内容保留；不将此安全限制描述为完整队列编辑能力。

源码、局部回归、7420 本地部署、远端 CI、设备与正式发布分别验证。候选尚有空任务首次历史读取兼容问题；完整两小时浸泡、当前设备恢复矩阵及发布门槛仍须核验，不以既往版本或单次浏览器样本冒充通过。

暂不生成正式标签、Release 或 APK。本候选只有经 beta 验证并满足 `PRODUCT_GOAL.md` 全部门槛后，才能合并 main 和正式发布。
