## 安装证据与归因修正

保留原来的依赖版本/完整性字段，仅将 yauzl 的 URL 改回反馈中的镜像地址，在隔离目录使用 Node 22.22.2 / npm 12.2.0、`allow-remote=none`、`ignore-scripts`：退出码 1，明确报 `EALLOWREMOTE`。同一最终 package/lock 的官方源版本退出码 0，安装 326 个平台适用包。430 条 resolved 均为 HTTPS 官方源且不含 URL 凭据；锁中的其他平台可选包不一定安装。

用户反馈中的“npm 10 默认禁 remote”不作为已核实结论。本机 npm 10.9.3 没有该配置；[npm 官方文档](https://docs.npmjs.com/using-npm/config/#allow-remote) 说明 npm 12 默认值为 `none`。后续向反馈者确认其 npm 版本和实际策略即可，不建议通过开启 remote 绕过锁文件问题。

工作区服务模块验证最初分别遇到沙箱临时文件重命名限制、缺少 better-sqlite3 原生构件。改用隔离临时目录并仅恢复已锁定 SQLite 构件后，服务模块检查通过；没有修改配置持久化或数据库业务代码。

## 公式依赖与安全边界

采用 KaTeX 0.19.0 替代自行实现公式排版、字体度量和 MathML 输出。只在既有会话渲染路径增加数学 token，不新增服务、数据库或持续轮询。新许可证位于 `public/third-party-notices/katex.txt`。

四种分隔符为 `$…$`、`$$…$$`、`\(...\)`、`\[…\]`。代码块和行内代码保持源码；未闭合、错误或超限公式保留可读内容。进入 KaTeX 前限制单公式 4000 字符、128 个控制序列、32 个未转义开组；自定义宏、别名、动态扩展和私有控制词直接保留源码，注释中的受限命令也保守回退。每次调用独立宏表，`trust=false`、最多 1000 次宏展开、尺寸限制 20em；这些选项不能单独提供同步执行的硬超时。普通 Markdown 的 HTML 消毒策略保留，生成公式单独消毒 MathML/SVG，禁止链接、外部图片等能力。[KaTeX 安全选项](https://katex.org/docs/security) 是基础限制的依据，调用前预算来自本轮宏放大实测。

体积参考：KaTeX 官方 minified JS 为 272868 字节（gzip 76584），CSS 为 24793 字节（gzip 3625）；字体随本地静态资源提供。实际 Vite 会话分块大小见构建日志，不能把上述库文件大小当作最终首屏增量。移除时撤销 `conversationMath.ts` 接入、公式专用消毒与 CSS、KaTeX 依赖/锁条目和专用测试即可，不改消息、任务、审批或恢复协议。

桌面行为比对复用了本地提取的 Codex 26.818.41509 数学/KaTeX 资源；本轮当前安装包枚举被环境拒绝，因此不声称这是当前桌面版逐像素对齐。页面验收使用独立 agent-browser、全新空白 profile 和候选静态预览，阻断 `/codex-api/**`，没有发送真实任务。
